# 無障礙斜坡道工程 GitHub Pages

此儲存庫提供國立臺南特殊教育學校無障礙斜坡道工程進度報告的靜態網頁版本。頁面以民國115年10月5日可查閱的公開報告資料整理，並保留連回完整原報告及公開附件的入口。

## 網站

GitHub Pages 網址：`https://hsiang0422-star.github.io/accessibility-ramp-progress/`

完整原報告：<https://accessibility-ramp-progress.c-h-hsiang0422.chatgpt.site/>

## 日後更新方式

1. 將新的進度表、核定函、會議紀錄、設計圖或照片提供給 Codex，並說明文件日期及哪些事項已核定、哪些仍待確認。
2. 請 Codex 對照原有網站與新資料，確認金額、日期、工期、招標狀態及文件連結，更新本儲存庫的 `index.html`，並保留歷程。
3. 檢視更新內容後，儲存庫的 `main` 分支每次更新都會由 GitHub Pages 自動重新發布。

更新網站時不要把尚未核定的建議或估算寫成定案。若附件有個資、簽名或限校內閱覽內容，先確認公開版本及分享權限。
